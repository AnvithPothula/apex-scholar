## The FRQ (AP Calculus AB, no calculator)

This is the question the practice test will show in beats 14 and 15. I'll load it into the test account's practice test so the photo answers exactly what's on screen.

**Question**

Let f be the function defined by f(x) = x³ − 3x² − 9x + 5.

(a) Find the x-coordinates of all relative extrema of f. Classify each as a relative maximum or a relative minimum. Justify your answer.

(b) On what open intervals is the graph of f concave up? Justify your answer.

(c) Find the absolute maximum value of f on the closed interval −2 ≤ x ≤ 4. Justify your answer.

**Rubric (9 points)**

| Part | Points |
|---|---|
| (a) | 1: f′(x) = 3x² − 6x − 9 · 1: critical points x = −1 and x = 3 · 1: relative max at x = −1, f′ changes + to − · 1: relative min at x = 3, f′ changes − to + |
| (b) | 1: f″(x) = 6x − 6 · 1: concave up on (1, ∞) · 1: because f″(x) > 0 there |
| (c) | 1: Candidates Test using x = −2, −1, 3, 4 · 1: answer, absolute max is 10 at x = −1 |

Correct values: f(−2) = 3, f(−1) = 10, f(3) = −22, f(4) = −15.

### What to write (copy this by hand)

The one deliberate mistake is in (c): f(−2) is worked out with a sign error on the −3x² term (+12 instead of −12), which gives 27 instead of 3 and the wrong final answer. Everything else is correct, so the grade should come back 8/9 with the missed point being (c)'s answer, and the feedback should say why.

```
(a)  f'(x) = 3x² − 6x − 9
           = 3(x − 3)(x + 1)

     f'(x) = 0  →  x = −1, x = 3

     f' > 0 for x < −1,  f' < 0 for −1 < x < 3,  f' > 0 for x > 3

     Relative max at x = −1 because f' changes from + to −.
     Relative min at x = 3 because f' changes from − to +.

(b)  f''(x) = 6x − 6

     f''(x) > 0 when x > 1

     f is concave up on (1, ∞) because f''(x) > 0 there.

(c)  Candidates: endpoints x = −2, x = 4 and critical points x = −1, x = 3

     f(−2) = −8 + 12 + 18 + 5 = 27        <- the deliberate mistake
     f(−1) = −1 − 3 + 9 + 5 = 10
     f(3)  = 27 − 27 − 27 + 5 = −22
     f(4)  = 64 − 48 − 36 + 5 = −15

     The absolute maximum value of f on [−2, 4] is 27, at x = −2.
```

Don't write the "deliberate mistake" note on the paper, of course.

### Tips for the photo
