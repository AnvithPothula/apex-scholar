# Bug sweep findings (2026-10-15)

## Dev environment
- cors-proxy + schoology-oauth not served under `npm start` (only ai-proxy runs in-process) -> Schedule calendar sync 503 in dev (user's paste).
- Google Analytics fires from localhost: .env has REACT_APP_GA_MEASUREMENT_ID, so dev traffic lands in the production GA property (comment in App.js says dev never sends).
- 21 ESLint problems, all in test files (import/first, jest/no-conditional-expect, unused vars).

## Global
- 404 page keeps the previous page's <title> on client navigation (e.g. "Terms of Service — Apex Scholar" on /no-such-page).
- Header logo "Apex Scholar" is an <h1> on every page -> two h1s per page.

## AI Tutors
- Tutor URLs use camelCase subject ids (/ai-tutors/artHistory) while Learn uses kebab (/study/ap-art-history).
- An old offline fallback ("I'm experiencing connectivity issues… I'll be back online shortly") was saved into the conversation as a real tutor message (3/16 session) and is shown as history.
- Every answer opens with "Hello Tester!" even mid-conversation.
- Opening a subject shows a blank page for ~3s before the chat renders.
- At ~800x690 the message pane is only ~186px tall (header + mode tabs + big input eat the rest); the user's own question scrolls out of view immediately.
- "Your Subjects" appears twice (page H1 and section heading).
- Practice MCQ mode: the chat auto-scrolls to the bottom, so on short screens the question stem is out of view and the student sees only the options.

## Smart Scheduler
- "Generate Smart Schedule" does nothing visible when a task is overdue; the reason ("generation paused — overdue tasks need attention") only goes to console.log. The overdue banner sits above, off-screen from the button.
- Page H1 "Scheduler" renders *below* the AI Study Schedule panel (visual order != DOM order); the schedule list is a nested fixed-height scroll box inside the page scroll, cutting the next day's card.
- "Refresh Schedule" is styled red (destructive) with no hint of what it does.

## Settings
- Calendar feed failure shows raw developer text to students: "Failed to configure calendar: Failed to configure calendar URL: All CORS proxy attempts failed. Last error: HTTP 503 … `netlify dev` …" (doubled prefix, jargon), plus a stray tiny red dot instead of an icon.
- Section tab bar overflows sideways ("Schoolo…" cut off) with no scroll affordance; the sticky tab bar covers the section headings when jumping (e.g. "Schoology Integration" title hidden under it).

## Solver
- Step equations containing \frac (e.g. d/dx) sit in an `overflow:auto` box a few px shorter than the formula, so each gets a tiny vertical scrollbar (steps 1 and 3 of a product-rule solution).
- Works end to end (~20 s for a typed question); subject tag says "General" for a calculus problem when no subject is chosen.

## Diagnostics
- Starting a diagnostic keeps the catalog's scroll position, and so does each "Next Question": the student lands below the question stem and "Question N of 15" header (scrollY 259 on Q2).
- Copy promises "15-25 adaptive questions that adjust to your skill level" and "hundreds of AP subjects"; the test is a fixed 15 questions, one per topic, across 35 subjects (39 AP courses exist, so 4 have no diagnostic).
- One question per topic makes the "Topic Breakdown" a list of 0/1 and 1/1 bars; results then say no topic had enough questions.
- "Start Diagnostic" buttons in the full grid all share the same accessible name (no subject in it), unlike the "Popular" ones.
- Diagnostic URLs carry the display name with a space (/diagnostics/AP%20Biology/start) — a third slug style alongside camelCase tutors and kebab Learn.
- Results suggest topics to study but don't link to the matching Learn units.

## Review
- Repeated-mistake detection is broken (Review.jsx ~430): `card.userAnswer.startsWith(letter(picked))` compares a stored answer *text* ("Glycolysis in the cytosol.") with a letter ("A"), so picking the same wrong answer says "Last time you put Glycolysis in the cytosol., so it's a different mistake this time." Also double punctuation "cytosol.,".
- Starting a session keeps the setup page's scroll position, hiding the "1 of 30 due" header.
- Works otherwise: grading keys 1–4, explanations, next card.

## Progress

- Streak shows "1 day" / "1 days" (grammar) although the account practiced on Oct 14 and 15 (practice test submitted on the 14th) — worth checking what counts as a study day.
- Study Time and Accuracy both show exactly "-11% vs. last month" — suspicious duplicate.

- "Recent Achievements" lists every achievement, not recent ones; "Inbox Zero — clear your review queue: Earned" shows next to 45 due cards (earned once, fine, but reads oddly).
- Study Activity heatmap: 7 rows labelled only M/W/F, cells stretch to large squares at ~800 px.

## Fix round (2026-10-16): what happened to each item
Every fix below was used in the browser on localhost (signed-in test account, guest on 127.0.0.1, phone 375 and wide 1280 where layout changed). Full suite 1033 tests passing, `npm run build` clean, ESLint clean across `src`.

**Fixed**
- Dev: cors-proxy, class-record-test, schoology-oauth, admin-stats run in-process under `npm start`; GA only in production builds; all test-file lint problems; dead `DrawingCanvas.jsx` and `tutors/MessageInput.jsx` removed.
- Global: 404 and timeline titles; one h1 per page; scroll resets on route change, Review cards, Diagnostics questions and results, flashcard study.
- AI proxy calls time out after 90 s with a plain message.
- Practice results: FRQ total is the sum of part scores; rubric parts lettered from the prompt's (A)…(D); short FRQs ask for the real point total (Bio/Chem 4, others 5) and the grader reads `points`; ungraded responses show "Not graded" with a "Grade it now" button that rescores only those, saves the test and re-credits classes; bare `^{\circ}` renders as °.
- Classes: credit never fired because `useAuth().user` is a plain object without `getIdToken`; the token now comes from `auth.currentUser`. Leaderboard ranks members with under 10 answers after real samples.
- Review: repeated-mistake check compares answer text, not a letter; quoted answers.
- Progress: countdown, Focus fallback, streak grammar, duplicate change line, one-shot achievements, rec dedupe, Learn/tutor activity counts toward Subject Explorer; heatmap cells fixed at 12 px and aligned with day labels.
- Diagnostics: honest copy (15 questions, spread across topics, no "adaptive"), named Start buttons, results link to the class in Learn.
- Flashcards: prompt stays visible above the answer, grade buttons on screen, phone buttons labelled, Study buttons named, "Didn't Know" adds the card to Review (so "spaced repetition" is true), Quizlet import is a native modal `<dialog>` (focus trapped, Escape closes).
- Scheduler: Generate explains the overdue block and scrolls to the banner; banner shows on load and hides when nothing is overdue; heading first on phones with no nested scroll boxes; "Rebuild Schedule" (neutral style) actually regenerates and refuses while tasks are overdue; header no longer wraps; task editor fields labelled.
- Settings: calendar errors in plain words, icon no longer shrinks to a dot, URL field labelled; section pill bar sticks under the header with a fade showing it scrolls.
- Tutors: failed replies aren't saved into the thread (toast instead); name used only in the first reply; composer one auto-growing row (message pane 186 → 240 px at 674×580); a tall reply (Practice MCQ) opens at its first line; "AI Tutors" heading; phone tabs fit one row with "Check steps"; Summarize explains itself when tapped without a file; back button says "Subjects".
- Learn: inline `\frac` no longer gets a tiny vertical scrollbar (also fixes solver steps); table-cell maths stays on one line.
- Bluebook: Mark for Review and cross-outs saved with auto-save and restored on resume.
- Guests: gate offers AI Tutors · Learn · Score calculator; `/start` shows Sign in.
- `/start`: no longer adds the subject to an existing student's subjects; links to the class in Learn named after the missed concept instead of claiming Unit 1.
- Solver: when no subject is picked the model names the course, and history uses it.
- Practice hub tagline no longer contradicts the Learn tile.
- Review queue: capped by size (~900 KB) as well as count.

**Not bugs (checked)**
- Learn-saved decks already store the same subject keys as manual decks.
- PackQuestion radios take their name from content; the reader tool just doesn't list `role="radio"` divs.
- Tutor "blank load" and other multi-second transitions: the test browser reports `visibilityState: hidden`, which pauses framer-motion's 150 ms exit; not reproducible in a visible tab.
- Outage notices with the retry widget are saved on purpose (they're excluded from model context).

**Deferred, with reason**
- Subject naming and URL slug styles across pages (tutors camelCase, Learn kebab, diagnostics display names; "AP U.S. History" vs "AP United States History"). Needs one decision on canonical display names and redirects for old URLs; a piecemeal rename would break saved links and history keys.
- Diagnostic "one question per topic" breakdown is a design limit of a 15-question test; the page already says so.
- A regrade of an old test can't add to class boards: the server only credits a just-finished test (deliberate anti-replay rule).
