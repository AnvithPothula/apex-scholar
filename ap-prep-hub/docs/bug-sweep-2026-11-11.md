Live site (apex-scholar.com, signed in as the test account) plus code changed since the
2026-10-15 sweep. Nothing below is fixed yet.

## Fixed during this sweep

- The SMTP2GO unsubscribe from 2026-11-08 was only in SMTP2GO's suppression list. It's now on the account too (`emailOptIn: false`, every email type off).
- Emails now send as "Apex Scholar" instead of the bare `no-reply` address (`senderOf` in email-broadcast.js; uncommitted).

## Checked and fine

- All 143 sitemap URLs except #3 return 200 with a matching canonical; no duplicate titles.
- Security headers: CSP, HSTS, X-Frame-Options DENY, nosniff, Referrer-Policy, Permissions-Policy.
- Firestore rules: every user collection is owner-only, server-only docs (`private`, `feedback`) are closed, admin status can't be self-granted, response logs are append-only.
- Signed-in pages load with no console errors: tutors, practice, practice tests, review, progress, classes, scheduler, flashcards, solver, diagnostics, settings, privacy, terms, calculators, study packs, timelines, 404.
- No horizontal overflow at 375 px on Progress, Scheduler, Practice tests, Flashcards, Settings.
- Tutor round trip through the Worker: answer in about 5 s, math renders.

## Not a bug (test-environment artifact)

- `/` looked blank for about 4 s before showing the tutors page. The browser pane was throttled to about 1 animation frame per 2 seconds, and route changes wait for a 0.15 s exit animation. Real browsers aren't affected.
